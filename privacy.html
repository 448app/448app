MONEY MATCH · มีผลตั้งแต่ 6 พฤศจิกายน 2569

Money Match (“แอป”) เป็นเครื่องมือวางแผนการเงินและจัดการงานสำหรับตัวแทนประกันชีวิตในหน่วย Money Match ภายใต้ 448 Wealth Group ดูแลระบบโดยผู้ดูแลของหน่วย นโยบายนี้อธิบายว่าแอปเก็บข้อมูลอะไร เก็บไว้ที่ไหน ใช้ทำอะไร และคุณมีสิทธิอะไรบ้าง

สรุปสั้น ๆ: ข้อมูลลูกค้าและแผนการเงินที่คุณบันทึกจะอยู่ในเครื่องของคุณ และ (ถ้าคุณเปิดใช้) ใน Google Drive ของคุณเอง เท่านั้น ไม่ถูกส่งไปเก็บที่เซิร์ฟเวอร์ของหน่วย ผู้ดูแลระบบเข้าถึงข้อมูลลูกค้าของคุณไม่ได้

1. ข้อมูลที่แอปเก็บ และเก็บไว้ที่ไหน

ประเภทข้อมูลรายละเอียดเก็บไว้ที่
บัญชีตัวแทน ชื่อ–นามสกุล อีเมล วันที่สมัคร สถานะการอนุมัติ และรูปโปรไฟล์ Google (กรณีเข้าสู่ระบบด้วย Google) ใช้เพื่อยืนยันตัวตนและอนุมัติสิทธิ์ใช้งานในหน่วย Firebase Authentication และ Cloud Firestore (บริการของ Google) ในโปรเจกต์ของหน่วย
ข้อมูลงานของตัวแทน ข้อมูลลูกค้า แผนการเงิน กรมธรรม์ นัดหมาย งาน กิจกรรม และรูปภาพที่คุณบันทึกในแอป ในเครื่องของคุณเท่านั้น (ที่เก็บข้อมูลของเบราว์เซอร์: localStorage และ IndexedDB)
สำเนาสำรอง (ถ้าเปิดใช้) สำเนาของข้อมูลงานข้างต้น เมื่อคุณกดเชื่อมต่อ “สำรองข้อมูลกับ Google Drive” ด้วยตัวเอง โฟลเดอร์ข้อมูลแอป (appDataFolder) ใน Google Drive ของบัญชี Google ที่คุณเลือกเอง
สถิติการใช้งาน จำนวนการเปิดหน้า อุปกรณ์ ประเทศ และเวลาใช้งาน แบบไม่ระบุตัวตน (เปิดใช้การปกปิดหมายเลข IP) ไม่ผูกกับข้อมูลลูกค้า Google Analytics

ผู้ให้บริการโฮสต์ไฟล์ของแอป (GitHub Pages) อาจเก็บบันทึกการเข้าถึงเซิร์ฟเวอร์ เช่น หมายเลข IP ตามนโยบายของผู้ให้บริการนั้น แอปไม่เก็บรหัสผ่านของคุณเอง การจัดการรหัสผ่านทำผ่าน Firebase Authentication

2. การเชื่อมต่อ Google Drive และข้อมูลจาก Google API

  • สิทธิ์ที่ขอ: https://www.googleapis.com/auth/drive.appdata เพียงรายการเดียว สิทธิ์นี้ให้แอปอ่านและเขียนได้เฉพาะไฟล์ที่แอปสร้างในโฟลเดอร์ข้อมูลแอปของคุณ แอปมองไม่เห็นและเข้าถึงไฟล์อื่นใน Google Drive ของคุณไม่ได้
  • ใช้ทำอะไร: สำรองข้อมูล กู้คืน และซิงก์ข้อมูลงานระหว่างอุปกรณ์ของคุณเท่านั้น ข้อมูลไหลระหว่างเบราว์เซอร์ของคุณกับ Google Drive ของคุณโดยตรง ไม่ผ่านเซิร์ฟเวอร์กลางของหน่วย
  • โทเค็นการเข้าถึง: เก็บชั่วคราวในเซสชันของเบราว์เซอร์และหมดอายุภายในประมาณ 1 ชั่วโมง ไม่ถูกส่งไปที่อื่น
  • ถอนสิทธิ์: ทำได้ทุกเมื่อที่ myaccount.google.com/permissions หรือกด “หยุดซิงก์” ในแอป และลบไฟล์สำรองได้ที่ Google Drive → การตั้งค่า → จัดการแอป

การใช้และการโอนข้อมูลที่ Money Match ได้รับจาก Google API เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use

3. การใช้ข้อมูล

แอปใช้ข้อมูลเพื่อให้บริการตามฟังก์ชันของแอปเท่านั้น ได้แก่ ยืนยันตัวตน อนุมัติสิทธิ์ใช้งานในหน่วย แสดงผลและคำนวณแผนการเงินให้คุณ และสำรอง/ซิงก์ข้อมูลตามที่คุณสั่ง แอปไม่ขาย ไม่ให้เช่า และไม่แบ่งปันข้อมูลของคุณหรือของลูกค้าคุณแก่บุคคลภายนอก และไม่ใช้ข้อมูลเพื่อการโฆษณา

4. ข้อมูลลูกค้าที่ตัวแทนบันทึก

ข้อมูลลูกค้าที่คุณบันทึกในแอปเป็นข้อมูลที่คุณเป็นผู้ควบคุมในฐานะตัวแทน คุณมีหน้าที่แจ้งและขอความยินยอมจากลูกค้าตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) และนโยบายของบริษัทประกันต้นสังกัด แอปเป็นเพียงเครื่องมือที่เก็บข้อมูลไว้ในเครื่องของคุณและในพื้นที่ของคุณเอง

5. ผู้ให้บริการภายนอกที่เกี่ยวข้อง

  • Google (Firebase Authentication, Cloud Firestore, Google Drive API, Google Analytics)
  • GitHub Pages (โฮสต์ไฟล์ของแอป ไม่เก็บข้อมูลผู้ใช้ของแอป)

6. ความปลอดภัย

แอปให้บริการผ่าน HTTPS เท่านั้น การเข้าสู่ระบบและรหัสผ่านจัดการโดย Firebase Authentication ข้อมูลงานไม่ออกจากเครื่องของคุณเว้นแต่คุณเปิดใช้การสำรองกับ Google Drive ของคุณเอง อย่างไรก็ตาม ไม่มีระบบใดปลอดภัยสมบูรณ์ โปรดตั้งรหัสล็อกอุปกรณ์และไม่ใช้แอปบนเครื่องสาธารณะ

7. ระยะเวลาเก็บรักษาและการลบข้อมูล

  • ข้อมูลในเครื่อง: อยู่จนกว่าคุณจะลบในแอป ออกจากระบบแล้วล้างข้อมูล หรือล้างข้อมูลเว็บไซต์ของเบราว์เซอร์
  • ไฟล์สำรองใน Google Drive: อยู่จนกว่าคุณจะลบผ่าน Google Drive (การตั้งค่า → จัดการแอป → ลบข้อมูลแอปที่ซ่อนอยู่)
  • บัญชีตัวแทน: แจ้งผู้ดูแลระบบทางอีเมลด้านล่างเพื่อลบบัญชีและข้อมูลที่เกี่ยวข้องในโปรเจกต์ของหน่วย

8. สิทธิของคุณ

คุณมีสิทธิขอเข้าถึง แก้ไข ลบ หรือขอสำเนาข้อมูลส่วนบุคคลของคุณ รวมถึงถอนความยินยอมการเชื่อมต่อ Google Drive ได้ทุกเมื่อ ติดต่อผู้ดูแลระบบตามช่องทางด้านล่าง

9. การเปลี่ยนแปลงนโยบาย

หากมีการเปลี่ยนแปลง จะประกาศที่หน้านี้พร้อมระบุวันที่มีผลใหม่ การใช้แอปต่อหลังวันที่มีผลถือว่ารับทราบนโยบายฉบับปรับปรุง
