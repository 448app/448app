คู่มือการใช้งาน

Money Match — เครื่องมือวางแผนการเงินและความคุ้มครองสำหรับตัวแทน

🚀 เริ่มต้นใช้งาน 🏠 เมนูหลัก 💰 วางแผนการเงิน 🎯 วางแผนชีวิต 📈 วิเคราะห์และแนะนำ 🧾 เครื่องมือ 💡 เคล็ดลับสำคัญ ❓ คำถามที่พบบ่อย
🚀

เริ่มต้นใช้งาน 4 ขั้น

1

เข้าสู่ระบบ

ล็อกอินด้วยบัญชีตัวแทนของคุณ (หากยังไม่มี ให้สมัครแล้วรอผู้ดูแลอนุมัติ) เมื่อเข้าสำเร็จจะมาที่หน้าแรก (Dashboard)

2

เพิ่มลูกค้า

ไปเมนู “รายชื่อลูกค้า” → เพิ่มลูกค้า กรอกชื่อ-นามสกุล วันเกิด และข้อมูลบุตร (ถ้ามี) — วันเกิดสำคัญมาก เพราะใช้คำนวณอายุ/เกษียณ/การศึกษา

3

เลือกลูกค้า แล้วกรอกข้อมูล

เลือกลูกค้าจากแถบด้านบน จากนั้นกรอกข้อมูลในเมนูต่าง ๆ — กระแสเงินสด สินทรัพย์ ประกัน เป้าหมาย ฯลฯ ระบบบันทึกให้อัตโนมัติทันทีที่กรอก

4

วิเคราะห์ + สร้างแผนให้ลูกค้า

ดู “ลำดับความสำคัญ” จัดอันดับเป้าหมาย แล้วไป “จัดทำแผน” หรือ “สรุปแผน” เพื่อสร้างไฟล์ PDF สรุปแผนสวย ๆ ให้ลูกค้า

🏠

เมนูหลัก

🏠
หน้าแรก (Dashboard)
ภาพรวมลูกค้าทั้งหมด · ปฏิทินนัดหมาย · แจ้งเตือนวันเกิดลูกค้าและกรมธรรม์ใกล้ครบกำหนด · งานที่ต้องทำ
💾 มีปุ่ม “Export / Import ข้อมูล” สำหรับสำรอง-กู้คืน อยู่ด้านล่างของหน้านี้
👥
รายชื่อลูกค้า
เพิ่ม/แก้ไขลูกค้า · ใส่รูป (ถ่ายด้วยกล้องหรืออัปโหลด) · วันเกิด · ข้อมูลติดต่อ · บุตร
👆 เลือกลูกค้าที่แถบด้านบนเพื่อทำงานกับคนนั้นในทุกเมนู
💰

วางแผนการเงิน

💰
กระแสเงินสด
บันทึกรายรับ-รายจ่ายต่อเดือน เพื่อดูว่าลูกค้าเหลือเงินออม/ลงทุนได้เท่าไร
💎
สินทรัพย์
ลิสต์สินทรัพย์ (เงินฝาก กองทุน อสังหา ฯลฯ) และหนี้สินทั้งหมด
⚖️
งบการเงิน
คำนวณความมั่งคั่งสุทธิ (สินทรัพย์ − หนี้สิน) จากข้อมูลที่กรอก
📐
อัตราส่วนการเงิน
ตรวจสุขภาพการเงินของลูกค้า — อัตราการออม สภาพคล่อง ภาระหนี้
🎯

วางแผนชีวิต

🎓
การศึกษาบุตร
วางแผนค่าเล่าเรียนบุตรตั้งแต่ ป.ตรี / ป.โท / ป.เอก พร้อมคิดเงินเฟ้อ
🛋️
วางแผนเกษียณ
คำนวณเงินที่ต้องเตรียมไว้ใช้หลังเกษียณ + จำลองสถานการณ์ (มีโหมดรักษาเงินต้น)
🎯
เป้าหมายชีวิต
ตั้งเป้าหมายการเงิน (บ้าน รถ ท่องเที่ยว ฯลฯ) พร้อมกำหนดเวลา
☂️
ประกันชีวิต · ประกันสุขภาพ
ประเมินทุนคุ้มครองที่เหมาะสม และค่ารักษา/โรคร้ายแรงที่ควรมี
📊
สรุปกรมธรรม์
รวมกรมธรรม์ที่ลูกค้ามีอยู่ + วิเคราะห์ช่องว่างความคุ้มครอง
📈

วิเคราะห์และแนะนำ

🎯
ลำดับความสำคัญ
จัดอันดับเป้าหมาย 1-7 (คลิกวงกลมแล้วเรียงเลขให้อัตโนมัติ) + กำหนดน้ำหนัก แล้วระบบช่วยจัดสรรงบ
📈
พอร์ตแนะนำ
แนะนำสัดส่วนพอร์ตการลงทุนที่เหมาะกับความเสี่ยงและเป้าหมายของลูกค้า
📋
สรุปแผน
สร้างไฟล์ PDF สรุปแผนครบวงจร (หน้าปก + การเงิน + เกษียณ + การศึกษา + ประกัน + โปรไฟล์ตัวแทน)
🖨️ กดสร้าง → เลือก “Save as PDF” ในหน้าต่างพิมพ์
📊
จัดทำแผน (One-Page Summary)
สร้างแผนแบบ 1 หน้า — เส้นเวลาเงิน (สะสม→เกษียณ→ถอนใช้) · ความคุ้มครองชีวิต/ทุพพลภาพ · สุขภาพ · แนบรูปประกอบได้ → ออกเป็น PDF
⏳
Life Timeline
เส้นเวลาเหตุการณ์สำคัญในชีวิตลูกค้า (เกษียณ เป้าหมาย จบการศึกษาบุตร ฯลฯ)
🧾

เครื่องมือ

🧾
คำนวณภาษี
คำนวณภาษีเงินได้บุคคลธรรมดาจากรายได้และค่าลดหย่อน
🧮
ลดหย่อนภาษี
เทียบช่อง “ปัจจุบัน” กับ “ปรับปรุง” เพื่อหาสิทธิ์ลดหย่อนเพิ่ม (เช่น ประกัน กองทุน) และดูภาษีที่ประหยัดได้
📅
นัดหมาย
บันทึกและจัดการนัดหมายกับลูกค้า แสดงในปฏิทินหน้าแรก
🔺
สามเหลี่ยมการเงิน
แผนภาพหลักการวางแผนการเงินเป็นขั้น (ป้องกันความเสี่ยง → ออม → ลงทุน → มั่งคั่ง)
👤
โปรไฟล์ตัวแทน
ข้อมูลตัวแทน รูป ใบอนุญาต รหัส AIA LINE — ใช้แสดงในหน้าปก PDF ที่ส่งให้ลูกค้า
💡

เคล็ดลับสำคัญ

💾

สำรองข้อมูลสม่ำเสมอ (สำคัญที่สุด!)

ข้อมูลลูกค้าทั้งหมดเก็บอยู่ใน เครื่องของคุณ (เบราว์เซอร์ + รูปใน IndexedDB) ไม่ได้อยู่บน cloud — ถ้าเปลี่ยนเครื่อง ล้างเบราว์เซอร์ หรือไม่เปิดแอปนาน (iOS ~7 วัน) ข้อมูลอาจหาย
→ ไปหน้าแรก กด “Export ข้อมูล” เก็บไฟล์ไว้เป็นประจำ · เครื่องใหม่ให้ “Import” ไฟล์กลับ · แอปจะเตือนถ้าคุณไม่ได้สำรองนาน

📱

ติดตั้งเป็นแอป (iPad / มือถือ)

เปิดในเบราว์เซอร์ (Safari/Chrome) → กดปุ่มแชร์ → “เพิ่มไปยังหน้าจอโฮม” — จะใช้งานได้เหมือนแอปจริง เต็มจอ และช่วยลดโอกาสข้อมูลหาย

⌨️

ย่อ/ขยายเมนูด้านซ้าย

กดปุ่ม ◀ ที่มุมเมนู หรือกด Ctrl + B เพื่อซ่อนเมนู ให้พื้นที่ทำงานกว้างขึ้น

🔄

อัปเดตเป็นเวอร์ชันล่าสุด

ปกติแอปจะอัปเดตให้เอง ถ้าเห็นของเก่า/แก้แล้วยังไม่เปลี่ยน ให้ reload หน้า (บนคอมกด Ctrl + Shift + R) เพื่อโหลดเวอร์ชันใหม่

❓

คำถามที่พบบ่อย

ข้อมูลลูกค้าเก็บที่ไหน ปลอดภัยไหม?▼
เก็บอยู่ใน เครื่องของคุณเอง (ในเบราว์เซอร์) ไม่ได้ส่งขึ้นเซิร์ฟเวอร์ภายนอก จึงไม่มีใครเข้าถึงได้ผ่านเน็ต แต่หมายความว่าถ้าเครื่องหาย/ล้างข้อมูล จะไม่มีสำเนาที่อื่น → ควร Export สำรอง เป็นประจำ และตั้งรหัสล็อกเครื่องไว้
จะย้ายข้อมูลไปเครื่องใหม่ยังไง?▼
ที่เครื่องเก่า: หน้าแรก → Export ข้อมูล จะได้ไฟล์ backup_448_….json · ที่เครื่องใหม่: ล็อกอินบัญชีเดิม → หน้าแรก → Import ข้อมูล เลือกไฟล์นั้น — ข้อมูลและรูปทั้งหมดจะกลับมาครบ
สร้างไฟล์ PDF ให้ลูกค้ายังไง?▼
ไปหน้า “สรุปแผน” (สรุปครบทุกส่วน) หรือ “จัดทำแผน” (One-Page Summary) → กดปุ่มสร้าง/บันทึก → ในหน้าต่างพิมพ์ที่เปิดขึ้น เลือกปลายทางเป็น “Save as PDF / บันทึกเป็น PDF”
ใช้บน iPad หรือมือถือได้ไหม?▼
ได้เลย ใช้ผ่านเบราว์เซอร์ได้ทุกอุปกรณ์ แนะนำให้ “เพิ่มไปยังหน้าจอโฮม” เพื่อใช้เหมือนแอปเต็มจอ (ดูหัวข้อเคล็ดลับด้านบน)
กรอกค่าแล้วขึ้น comma (,) ให้อัตโนมัติไหม?▼
ช่องกรอกเงินส่วนใหญ่จะใส่จุลภาคหลักพันให้อัตโนมัติระหว่างพิมพ์ (เช่น 100,000) เพื่ออ่านง่าย โดยยังเก็บเป็นตัวเลขจริงเบื้องหลัง
เผลอไม่ได้สำรอง แล้วข้อมูลหาย กู้ได้ไหม?▼
ถ้าไม่มีไฟล์ Export สำรองไว้ จะ กู้คืนไม่ได้ เพราะข้อมูลอยู่ในเครื่องเท่านั้น — นี่คือเหตุผลที่ควร Export สำรองอย่างสม่ำเสมอ (แอปมีมาตรวัดพื้นที่และการเตือนสำรองช่วยเตือนคุณ)

ต้องการความช่วยเหลือเพิ่มเติม?
